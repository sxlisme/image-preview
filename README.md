# 图片在线预览

一个简洁的图片预览工具，支持照片墙、全屏预览和高级模式。

## 功能

- **全部图片** - 上传本地图片或整个文件夹，以照片墙形式展示
- **全屏预览** - 点击缩略图进入全屏，点击左右区域或使用方向键切换图片
- **高级模式** - 添加文字水印和频谱动画效果
  - 快速填充文字模板（essential; / playlist. / GAME OVER）
  - 自定义文字颜色、字体、字号
  - 开启频谱动画
  - 毛玻璃背景效果

## 技术栈

- Vue 3 + Vite
- Ant Design Vue
- Canvas 频谱动画

## 本地运行

```bash
npm install
npm run dev
```
